# 1.2召唤引导技术
## 1.2.1两波次光电探测侦察无人机实时相对位置计算
### 1.2.1.1两波次光电探测侦察无人机“惯导/时空对准”
由于惯性导航累积误差较大，两波次光电探测侦察无人机之间，在飞行过程中需要定期进行“惯导/时空对准”（通过无线通信方式完成）。

为保证高效完成转弯和召唤引导，需在第2波次无人机转弯前触发一次空中“惯导/时空对准”，利用机间/编队间通信将空间位置及当前时刻信息进行统一，确保机间/编队间时空信息误差在极小的可接受范围内。

```
1. 如何进行“惯导/时空对准”（通过无线通信方式完成）？
2. 第2波次无人机转弯前要触发“惯导/时空对准”
```
### 1.2.1.2两波次光电探测侦察无人机相对位置计算
在第2波次无人机转弯期间，以一定时间间隔定时向第1波次无人机通报自身位置，第1波次无人机根据收到的第2波火无人机位置，计算两波次无人机之间的相对位置。

4. 第1波无人机收到第2波的位置后，需要计算两波无人机之间的相对位置，是两波无人机中心相对位置的计算吗？

## 1.2.2第1波次光电探测侦察无人机引导终点位置与速度推算
### 1.2.2.1第1波次光电探测侦察无人机引导终点有效位置区域推算
为便于第1波次无人机后续实施占位，引导终点的有效位置区域可以设置为2种情况：一是保证引导占位后敌群前进方向的后、左、右边缘，均在我方第1波次光电探测侦察无人机的视场范围内；二是保证引导占位后敌群前进方向的前（去除已被第2波次收入视场的目标）、左、右边缘，均在我方第1波次光电探测侦察无人机的视场范围内。

在第2波次无人机完成转弯或在转弯过程中已稳定捕获敌群目标时，第1波次无人机开始实施转弯，并根据计算得到的两波次无人机相对位置、第2波次过顶敌群后的终点占位位置、敌群航速航向、敌群编队队形等，对第1波次无人机的引导终点的有效位置区域进行推算。

此外，还可预先推算第1波次中各单架无人机的引导终点位置，由于引导终点位置主要决定了引导占位后的伴随侦察编队阵位，可以以机动能量最小化为目标，将距离第2波次无人机/敌群目标较远的无人机引导终点设置为靠近敌群尾后，而将距离第1波次无人机/敌群目标较近的无人机引导终点设置为靠近敌群前沿（去除已被第2波次收入视场的目标）
### 1.2.2.2第1波次光电探测侦察无人机引导终点有效速度范围推算
为便于第1波次无人机后续实施占位，引导终点的有效速度范围可以设置为2种情况：一是终点的速度不高（从低于敌群速度，到略高于敌群速度），后续需要加速以过顶敌群；二是显著高于敌群速度，后续过顶敌群时需要减速。

引导终点的有效速度范围，主要依据敌群运动速度、第1波次光电探测侦察无人机机动能力（不同转弯速度及对应转弯半径、加速及减速能力等）推算。
## 1.2.3、第1波次光电探测侦察无人机引导策略
### 1.2.3.1第1波次光电探测侦察无人机引导飞行次序推算
第1波次无人机的引导飞行次序，主要涉及第1波次的所有无人机，以及与敌群迎头飞行时第2波次中最靠前的几架无人机（负责在第1波次与敌群交错丢失敌群信息后，且第2波次无人机未完成转弯占位和捕获敌群信息前，“对敌群进行接力迎头侦察）。

引导飞行次序如下：第1波次无人机在与敌群交错后迅即实施转弯，等待同向侦察稳定捕获敌群的第2波次无人机召唤；第2波次接力迎头侦察的无人机，按与敌群交错丢失敌群信息的次序，接续实施转弯，并等待实施同向侦察稳定捕获敌群的第2波次无人机召唤。
### 1.2.3.2第1波次光电探测侦察无人机引导飞行航迹推算
主要根据第1波次无人机引导终点的有效位置区域和有效速度范围，推算各无人机的引导飞行航迹与航速，各无人机在引导飞行过程中任意时刻的航迹应避免冲突、碰撞风险、保持一定安全空间。

为得到较为理想的协同引导飞行航迹和航速，需要对空间进行网格化细分，从而实现集群空间运动的精确控制。
